# Rhombix Technologies — Project 1: Linux Fundamentals

## Overview

This project was completed as part of the Rhombix Technologies internship.

The objective was to practice fundamental Linux command-line operations, including file and directory management, file editing, permissions, system resource monitoring, process management, package management, and basic shell scripting.

## Environment

- Operating System: Ubuntu 24.04.4 LTS
- Shell: Bash
- User: nasir

## Topics Covered

### 1. File Navigation
- pwd
- ls
- cd
- find

### 2. File and Directory Management
- mkdir
- touch
- cp
- mv
- rm

### 3. File Viewing and Editing
- cat
- nano
- less
- head
- tail
- grep
- wc
- diff

### 4. Linux Permissions
- ls -l
- chmod
- chown

### 5. Process Management
- ps
- top

### 6. System Resources
- free
- df
- du
- lscpu

### 7. Package Management
- apt update
- apt install
- apt show
- dpkg

### 8. Shell Scripting

A basic system information script was created using Bash.
